# Spreditor, a DOS sprite editor.

You can launch the program with
  spredit file
  spredit infile outfile

  if using the infile outfile variant, it only reads from the infile, and only writes to the outfile.

Change current colour by pressing the colours on the left-hand side of the screen, and place them by clicking within the canvas.
Right click to set pixel to current colour, left click to set pixel to black, middle click to set the entire canvas to current colour.
S to save, E to exit.
